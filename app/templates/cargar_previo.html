¿No tienes un Excel todavía?

Descarga la plantilla oficial con todas las columnas que reconoce el sistema (Código del Bien, Código Anterior, Bien, Serie/ Identificación, Custodio Actual, etc.), llénala y luego súbela aquí abajo.

Descargar plantilla

El archivo se sube primero a una tabla de staging (Inventario Previo) para que un Administrador pueda revisar y verificar cada fila antes de pasarla al inventario oficial. Se aceptan archivos .xlsx o .xls, incluso de gran tamaño (hasta ~20,000 filas).

Cómo se procesa tu Excel
  • El sistema reconoce automáticamente los 46 campos oficiales del inventario (Bien, Serie, Modelo, Marca, Color, Valor, Custodio, Ubicación, Cuenta Contable, etc.), sin importar el orden de las columnas.
  • Cada campo admite varios encabezados alternativos (por ejemplo, para el custodio: "Custodio Actual", "USUARIO 2025" o "USUARIO 2024" — se usa el primero que tenga dato en cada fila).
  • Si una fila no trae un código de bien válido (vacío o textos como "SIN CODIGO ESBYE"/"INGRESAR"), se le asigna un código provisional automáticamente — no se descarta.
  • Si el mismo código aparece repetido en el archivo, se conserva la fila más completa.
  • Al subir un archivo sobre datos que ya existen, los complementa y actualiza (no borra información previa con campos vacíos del nuevo archivo).
